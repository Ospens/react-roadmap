    О проекте #

    Планировщик задач - это простое приложение для управления задачами. Наше будет иметь следующие возможности:

    1. Запись задач: Позволяет пользователю записывать задачи или дела, которые нужно выполнить. Например, «купить молоко» или «закончить проект».
    2. Отметка выполнения: Когда задача выполнена, её можно отметить как завершённую.
    3. Удаление: Можно удалять их, если они больше не актуальны.

    Чему научишься #

    • TypeScript. Это как JavaScript, но с типами. Сейчас это стандарт индустрии и реальные проекты пишутся именно на TS
    • Продвинутые и современные подходы при работе с Redux
    • Узнаем как обрабатывать и хранить данные, введенные пользователем
    • Узнаем больше про утилитарные классы или как верстать без CSS

    Техническое задание #

    Макет приложения

    https://www.figma.com/file/h37h7NmMTe6yI28B08Q7Vq/Todo-App-(Community)?type=design&node-id=0-1&mode=design

    1. Верстка должна быть выполнена на Tailwind
    2. Поле ввода “Новая задача” (элемент input). Должен содержать placeholder “Новая задача”.
    3. Кнопка (button) “+”. Добавляет контент, который введен в поле name. Кнопка должна быть отключена, если в поле name пусто. Когда кнопка отключена она должна быть серого цвета, а при наведении на нее курсор должен становиться перечеркнутым.
    4. Поле ввода и кнопка должны быть внутри формы. (см. материалы)
    5. Список дел. После создания задачи она попадает в этот список. Список задач идет в порядке добавления: новые появляется вверху.
      1. Каждый элемент списка должен содержать: чекбокс, название, которые мы ввели в поле ввода name, кнопку “Удалить”
      2. Заголовок должен соответствовать шаблону: “Список дел - X”, где X - количество элементов в списке.
    6. Выполненные дела. При нажатии на чекбокс он должен становиться активным, название должно зачёркиваться, а элемент должен быть перемещен в список “Завершено” (т.е. активные элементы должны быть вверху, а выполнение в конце списка)
      1. Заголовок должен соответствовать шаблону: “Завершено - X”, где X - количество элементов в списке.
    7. При нажатии на кнопку “Удалить” должен появляться диалог “Вы действительно хотите удалить {название элемента}?” При выборе “Да” - убрать элемент из списка. При выборе “Нет” - ничего не происходит.
