# Камень-ножницы-бумага

## О проекте

[Известная игра](https://ru.wikipedia.org/wiki/%D0%9A%D0%B0%D0%BC%D0%B5%D0%BD%D1%8C,_%D0%BD%D0%BE%D0%B6%D0%BD%D0%B8%D1%86%D1%8B,_%D0%B1%D1%83%D0%BC%D0%B0%D0%B3%D0%B0) на которой мы начнем изучение популярной библиотеки и основного инструмента - React.js.

В этом уроке примитивная верстка, основная задача по стилизации - разобраться с bootstrap и его компонентами.

## Чему научишься

В этом уроке ты начнешь знакомство с **Node.JS** экосистемой **React**:

- Настроишь локальный сервер для разработки
- Узнаешь про менеджеры пакетов
- Освоишь азы библиотеки React
- Разберешься с менеджером состояний
- Узнаешь про фреймворки для стилизации
- Настроишь сборщик приложений и статический анализатор кода

С этого урока начинается программирование, которое приближенно к реальным задачам, где люди работают в командах, а значит код, который вы пишете, должен не просто работать, но еще быть **читаемым**, **поддерживаемым** и **надежным.**

## Материалы для подготовки


> Список материалов может меняться время от времени. Самостоятельный поиск других источников приветствуется

- **Node.JS**. Есть два варианта работы с нодой:
    - **Простой**. Установить последнюю версию с официального сайта [https://nodejs.org/en](https://nodejs.org/en). Этого способа хватит для всех дальнейших проектов.
    - **Продвинутый.** Исользовать **nvm** ([Windows](https://github.com/coreybutler/nvm-windows), [macOS/linux](https://github.com/nvm-sh/nvm)). Этот менеджер позволяет иметь несколько установленных версий ноды и переключаться между ними. Если возникли проблемы с установкой - не тратье сейчас время, сосредоточьтесь на проекте и используйте простой способ. Вы всегда сможете перейти на продвинутый способ без вреда для существующих проектов.
- **Менеджеры пакетов.** [https://www.youtube.com/watch?v=FDfvuNbSs4U](https://www.youtube.com/watch?v=FDfvuNbSs4U)
- [https://ru.legacy.reactjs.org/docs/getting-started.html](https://ru.legacy.reactjs.org/docs/getting-started.html) - старая документация, но база в ней все еще актуальная, а понятия объяснены проще и структурирование + почти вся дока на русском.
- [https://react.dev/blog/2023/03/16/introducing-react-dev](https://react.dev/blog/2023/03/16/introducing-react-dev) - новая документация React. Если какие-то моменты не понятны из старой версии - попробуйте поискать здесь. Здесь же больше глубоких моментов, пока можете не заострять на них внимание.
- [ESlint инструкция](https://it-dev-journal.ru/articles/kak-nastroit-es-lint-i-prettier-v-react-prilozhenii) ([запасная инструкция](https://www.freecodecamp.org/news/how-to-add-eslint-to-your-react-project/)). Сейчас не нужно придумывать свои правила. Проследите чтобы в вашем **.eslintrc** файле были следующие строчки. Остальное пока не важно.

```JSON
"extends": [
  "eslint:recommended",
  "plugin:react/recommended",
  "plugin:prettier/recommended"
]
```

- **Состояние приложения.** [https://redux.js.org/](https://redux.js.org/) - Самый популярный менеджер состояния.
- [https://getbootstrap.com/docs/5.3/getting-started/introduction/](https://getbootstrap.com/docs/5.3/getting-started/introduction/) - один из популярных фреймворков для стилизации. После блока **Getting started** обратите внимание на **Componenets**, код отсюда понадобится для выполнения проекта
- [https://vitejs.dev/guide/](https://vitejs.dev/guide/) - Современный, набирающий популярность, сборщик приложений. Очень прост в настройке. Будем использовать его в этом и следующем уроках.
- [https://habr.com/ru/companies/itelma/articles/546372/](https://habr.com/ru/companies/itelma/articles/546372/)
- Пример структуры приложения [https://devprac.ru/books/reactjs/обзор-файловой-структуры-react-приложени/](https://devprac.ru/books/reactjs/обзор-файловой-структуры-react-приложени/). Такая организация папок была популярна раньше, и все еще встречается на старых проектах. Она называется folder-by-type, т.е. код группирован по техническим критериям, а не по бизнес требованиям. Из-за этого с ней есть проблемы, даже на средних проектах. Но я рекомендую ее по следующим причинам:
    - Она проще в понимании и в маленьких проектах с ней нет проблем
    - Если на рабочем проекте попадется такая структура - буде проще в ней ориентироваться
    - В следующих уроках мы изучим современные подходы к проектированию, а так же разберемся как делать свои.
- И так как этот проект - отправная точка для промышленного программирования, то рекомендую обзавестись литературой программиста: “**Совершенный код”** Стива Макконнелла (или **“Чистый код”** Роберта Мартина). Это не художественная литература, а скорее энциклопедии. Я не советую читать их от корки до корки, а обращаться к определенному разделу по необходимости. В этом проекте можно ознакомиться с разделом “Мастерство программирования”.

1. Верстка должна быть выполнена на bootstrap
2. Для хранения состояния приложения должен быть использован redux
3. У кнопки с жестами должен быть эффект при наведении: кнопка становится полностью синей.
4. После выбора жеста игроком должна быть задержка в 2 секунды (симуляция долгой работы скрипта бота)
5. Выбор жеста ботом должен быть абсолютно случайным.
6. Когда игрок ожидает жест бота выбранная кнопка должна оставаться синей
7. После задержки добавляется запись в таблицу
    1. Номер раунда
    2. Жестк игрока
    3. Жест ИИ
    4. Результат
8. Итоги раундов должны прокручиваться, если не помещаются на экран
9. Верстка должна быть адаптивной
