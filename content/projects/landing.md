# Визитка

## О проекте

Сайт-визитка - это аналог обычной визитки, но в интернете. Это веб-страница, на которой содержится информация о человеке или компании. Примеры: [сайт компании](https://crazypanda.ru/ru/), [персональная визитка](https://nikitashirokov.com/).

## Чему научишься

Верстка - это база всего web frontend’а. Следующие уроки, как и реальная работа фронтенд разработчиком, обязывают знать верстку. В этом уроке ты освоишь:

- **Основы HTML**: понимание структуры веб-страницы, умение использовать различные теги для создания контента.
- **Основы CSS**: стилизация элементов страницы, использование селекторов, классов и идентификаторов для применения стилей.
- **Адаптивную верстку**: сайты, которые корректно отображаются на различных устройствах и размерах экрана
- **Взаимодействие с макетам.** Макеты этого урока находятся в Figma, что максимально приближено к реальному процессу разработки. Сейчас Figma де-факто стандарт для UI дизайна.
- **Git.** Освоим базовые команды системы контроля версий и поймем для чего она вообще нужна.

- **Публикация проекта**. Опубликуйте финальный код проекта на [https://github.com/](https://github.com/). Будем плюсом, если разберетесь с Git’ом и будете коммитить проект по частям.
- **Следование макету.** Обратите внимание на отступы, указанные в макете. Они должны быть точно воспроизведены в вашем коде, чтобы сайт выглядел аккуратно и профессионально.
- **Используйте современные CSS свойства.** Применяйте flexbox, grid и медиазапросы для адаптивности. Эти инструменты помогают легко управлять расположением элементов на странице.
- **Использование CSS переменных для цветов.** Определите основные цвета вашего сайта как CSS переменные. Это упростит управление цветовой схемой сайта и облегчает внесение изменений.
- **Используйте семантические теги**. Выбирайте правильные теги для структуры вашего сайта (например, `**header**` для шапки, `**footer**` для подвала сайта). Это помогает поисковым системам лучше понимать содержимое вашего сайта и делает его более доступным для людей с ограниченными возможностями.
- **Шрифт**. Используйте шрифт **VALORANT** из макета для английского текста. Если вы решите добавить тексты на русском (кириллица) - используйте шрифт **Play**.
- **Адаптивность**. Сайт должен хорошо смотреться на устройствах с различной шириной экрана от 1000 до 2000 пикселей. Используйте медиа запросы, flexbox и grid для достижения этой цели.
- **Фото владельца.** Подставьте вместо фотографии-заглушки любую фотографию по вашему выбору.
- **Эффект наведения на фото**. Высота изображение увеличивается, имя съезжает вниз, а сбоку выезжает красный полупрозрачный фон.
- **Анимация ссылок.** При наведении на ссылки в шапке они должны анимироваться в соответствии с дизайном.
- **Плавная прокрутка.** Реализуйте плавную прокрутку к разделам сайта при клике на ссылки в шапке и возврат к началу страницы при клике на заголовки секций
- **Реализация разделов "Проекты" и "СММ".** Эти разделы можно сделать согласно представленному дизайну без дополнительных изменений.
